# VCB-Bench attribution

Source: Tencent/VCB-Bench, https://huggingface.co/datasets/tencent/VCB-Bench , dataset snapshot c0a083c335363046032c1e382b05546ad5ef0692. Code protocol: https://github.com/Tencent/VCB-Bench/tree/542990571e5b6e3fbce4a318492aec5607aaee3c . Dataset license: CC-BY-4.0, see LICENSE-Dataset.txt.

This release includes 50 mixed-category records sampled without replacement using seed 20261105, 64 audio files, their annotations and provenance. Audio was converted to mono 16 kHz PCM16 without trimming or augmentation; absolute host paths in metadata are replaced for portability. Model-generated audio/text and performance measurements are identified separately from original benchmark references.
