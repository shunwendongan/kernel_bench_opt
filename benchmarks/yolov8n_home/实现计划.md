# YOLOv8n 检测首轮实现计划

## 目标

完成模型选型、数据抽样、预处理、RK3588 实测与结果交付。任务是目标检测。采用 RK3588 内置 NPU。

## 实施步骤

1. 核对四份附件、项目历史及板端环境。冻结模型来源、软件版本与文件哈希。
2. 首选 YOLOv8n、640×640、batch=1、FP16 非量化。复用 Rockchip 官方部署导出。选择 COCO val2017 家庭相关目标子集。按 8 类各取 5 张，共 40 张，固定 seed=42。四组为瓶/杯、椅/沙发、床/餐桌、电视/笔记本电脑。保留真实标注、原图和抽样规则。
3. 固定 RGB letterbox 预处理。保存补边、缩放比例、输入张量及哈希。用同一 ONNX、同一预处理在 CPU 生成参考输出。先检查数值和检测结果，再上板采性能。
4. 正常轮：模型常驻，预热 3 次，各样本重复 10 次。详细轮：另建 context，启用 PERF_DETAIL，各样本采集一次。单列加载、预处理、输入提交、模型执行、输出获取和后处理。
5. 解析实际部署图与报告。按真实张量索引建立依赖。每个样本最多保留 4 个连通且节点不重叠的热点。边界张量值未捕获时标记不可独立重放。
6. 核验样本数、哈希、输出、报告和 JSONL。交付首轮简报、SOP、复现代码及原始证据。

## 验收口径

- 全部选中样本都有执行状态。失败记录保留原因。
- 正常性能与详细节点耗时分别统计。
- 硬件温度、频率和负载保存实测快照。未采数据记 null。
- 家庭物品标签只表示场景相关性，不等同真实家庭域标注。
- 小样本 AP 仅描述当前子集，不代替 COCO 全验证集精度。
- 热点节点耗时之和不称为独立子图墙钟时间。
- 不把运行库入口时间称为内部算子库 API 或设备 kernel 时间。

## 隔离与产物位置

本地新增目录：`benchmarks/yolov8n_home/`。
板端使用独立的新实验目录。模型、数据、环境与运行产物不覆盖既有 Qwen 或姿态实验。
复现工具使用本地独立 Python 环境。先验证影响结果正确性的关键行为。
