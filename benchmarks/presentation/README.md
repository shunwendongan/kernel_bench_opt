# YOLO 小组汇报

离线入口：[`2026-11-06_YOLOv8n_RK3588_小组汇报.html`](../../汇报材料/2026-11-06_YOLOv8n_RK3588_小组汇报.html)。图片、数据、CSS 和 JavaScript 均内嵌，无需服务或联网。

共 11 页，涵盖模型、数据与预处理、正常轮分段延迟、详细轮热点类型、模块依赖图、交互节点图、热点子图、质量状态与后续工作。

## 数据边界

首轮正常轮 400 次，详细轮 40 图各一次。严格质量门槛失败，性能只用于诊断。通用轮仅完成 40 图开发检查，独立 4960 图未正式验收。

模块、类型、阶段的时间是节点时间派生求和。分组 P95 按每个样本的组内总和计算，不能相加节点 P95。Backbone/Neck/Head 是架构语义注释，不是 RKNN 导出的阶段字段。

108 个节点、257 个张量、138 条边来自同一编译模型。25 个模块的 30 条连边由真实节点边折叠。没有采集内部张量值，热点不可独立重放。

## 复建

`report_data.json` 保存已核验的统计与来源哈希。生成器读取原始模型、数据和运行归档。它不启动推理或下载，也不重新计算 COCO AP。

在项目根目录、安装 `benchmarks/requirements.txt` 后运行：

```bash
python -B benchmarks/presentation/collect_report_data.py
python -B benchmarks/presentation/build_report.py
python -B -m pytest benchmarks/presentation/tests -q -p no:cacheprovider
```

第一条命令需要恢复本项目原始归档。第二条命令需要冻结清单、示例原图与 RGB 输入。仓库不包含全部模型和数据。直接打开已生成 HTML 不依赖这些文件。

缺少原始图归档时，两项原始数据集成测试明确跳过。其余测试核对内嵌数据身份、质量边界、离线资源和真实模块边。资源存在但损坏时仍会失败。

模板为 `yolo_report.template.html`。修改模板或汇报数据后必须重新构建 HTML，再运行测试。
