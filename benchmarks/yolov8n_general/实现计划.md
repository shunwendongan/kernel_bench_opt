# RK3588 通用目标检测第二轮实现计划

## 修改前计划

1. 核对首轮证据与板端环境。用旧 40 图定位分类概率差异。
2. 冻结通用数据、部署配置和验收协议。准备 COCO val2017 全部图片，将旧 40 图划为开发集，其余作为独立验收集。
3. 修正分类输出路径并完成开发验证。模型冻结后执行独立质量验收，再分开采集正常性能和详细 profiling。
4. 逐项核验图、热点、运行证据和数据覆盖。交付中文报告、复跑命令和可校验复现包。

## 数据与范围

- 沿用固定 Rockchip YOLOv8n 检测权重。FP16 非量化，batch=1，RGB 640×640。
- COCO val2017 提供日常通用物体检测覆盖。包含人、交通工具、动物、运动用品、食品、室内物品等类别。
- 从完整验证划分中扣除首轮 40 张开发样本。正式验收只使用未用于本轮调试的剩余样本。
- 不将目标类别直接当成真实场景标签。对性能子集另做图像审查，并保留不确定性。
- 性能子集预先固定 80 张。分层覆盖人员、交通工具、动物、运动用品、食品餐具、家具、电子设备和其他常见物品，每层 10 张。
- 数量、类别、crowd、目标尺度和许可由原始标注程序化核验。所有选定图片保留全部类别标注，包括零预测图。

## 部署修正候选

旧证据显示分类与求和输出存在概率下限，Lite2 与 C API 输出一致。先尝试将最终分类 Sigmoid 指定到 CPU。若编译器不支持该配置，则导出真实分类 logits，并在 CPU 执行稳定 Sigmoid 和分数求和。只改变执行位置，核对原始 ONNX 数学等价性。使用旧 40 图评估，冻结候选后才接触独立验收结果。

## 预注册质量门槛

- 所有冻结样本、输入哈希、输出数量与形状均一致。推理失败数为零。全部输出为有限值。
- 三个框回归输出逐张量相对 L2 不超过 0.02。
- 三个分类概率输出逐张量 RMSE 不超过 0.001。概率范围须为 [0,1]。
- 三个辅助分数输出逐张量 MAE 不超过 0.005。此输出为分类概率求和后裁剪到 [0,1]，不是 objectness。
- confidence=0.25、NMS IoU=0.45 时，同类框按 IoU≥0.90 匹配。全验收集参考匹配率与实际匹配率均至少 0.95。
- 标注评估采用 confidence=0.001、NMS IoU=0.65、max_det=300、COCO 标准 maxDets=[1,10,100]。
- RKNN 的 AP@[0.5:0.95] 至少 0.30，AP50 至少 0.45，AR100 至少 0.45。
- 相对原始 ONNX，AP 下降至多 0.01，AP50/AP75 下降至多 0.015，small/medium/large AP 各下降至多 0.02。
- 对具有至少 100 个非 crowd 实例且分布于至少 20 张验收图的类别，逐类 AP 下降至多 0.05。其他类别照常报告，不单独设硬门槛。
- 所有硬门槛同时通过，才标为“本轮通用目标检测技术质量验收通过”。这不构成夜间、红外、工业缺陷、道路安全或任意产品部署分布的验收。
- 若失败，保留结果与原因。不得在看到验收结果后调整门槛并追认通过。

## 性能与证据

- 模型常驻。正常轮预热 3 次，每图重复 10 次。详细轮独立 context，每图采集一次。
- core mask=7。线程配置、频率、温度、负载和内存保存实测证据。未锁频时明确披露。
- 端到端包括读取解码、预处理、RKNN 调用、CPU 分类激活与 DFL/NMS。加载、保存、评估、绘图不计入。
- 从本轮实际编译模型重新解析 producer/consumer，逐报告绑定节点。
- 每个原始性能样本最多四个连通、节点不重叠的热点。节点时间求和不是独立子图墙钟时间。
- 未捕获内部边界值时，`subgraph_io_available=false`、`replayable=false`。
- 保留首轮目录和失败结论。新目录为 `benchmarks/yolov8n_general/`。
